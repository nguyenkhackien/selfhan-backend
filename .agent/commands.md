# Commands

Use existing npm scripts:

```bash
npm install
npm run start:dev
npm run build
npm run format
npm run lint
npm run typecheck
npm test
npm run test:integration
npm run test:cov
npm run migration:generate
npm run migration:run
npm run migration:revert
npm run migration:status
```

Do not change package manager, remove lockfiles, run destructive commands, run production migrations locally, or force dependency conflicts without diagnosing them.
