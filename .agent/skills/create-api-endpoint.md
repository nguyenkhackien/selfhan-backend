# Create API Endpoint

Before implementation identify actor, permission, ownership/tenant scope, input/output, database reads/writes, transaction, side effects, idempotency, audit needs, and failures.

Create request/response DTOs, validation, use-case input/output, authorization, repository operation, typed error mapping, API documentation when enabled, and tests. Cover invalid input, missing authentication, insufficient permission, not found, conflict, dependency error, and unexpected error when applicable.
